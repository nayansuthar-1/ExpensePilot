# 💰 Expense Tracker App

A modern Flutter-based Expense Tracker application with Firebase authentication and real-time database integration.

---

## 🚀 Features

- 🔐 Firebase Authentication (Login / Signup)
- 📊 Monthly expense analytics
- 📈 Income vs Expense tracking
- 🗂 User-based data isolation
- 🌙 Dark mode support
- 📄 PDF report export
- ☁️ Cloud Firestore backend
- 🤖 AI-powered budgeting insights (if enabled)

---

## 🛠 Tech Stack

- Flutter
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Flutter PDF
- Provider / State Management
